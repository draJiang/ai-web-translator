AI 服务商设置

说明

  • 当前版本固定使用一个内置 Prompt：把网页英文正文改写为 CEFR B1 难度，保留原意、缩短长句、替换生僻词，保留的难词附上简短英文释义，方便边读边学。
  • OpenAI：调用 api.openai.com/v1/chat/completions，需要 OpenAI API Key。
  • Anthropic Claude：调用 api.anthropic.com/v1/messages，需要 Anthropic API Key。
  • Ollama：默认连接 Ollama Cloud（https://ollama.com），填入你的 Ollama API Key；若用本地 Ollama，把 Base URL 改成 http://localhost:11434，一般无需 API Key。
  • 自定义：任意兼容 OpenAI /chat/completions 协议的服务（如自建网关、其它模型供应商）。
  • 更换 Base URL 到官方以外的地址时，浏览器会弹出一次性授权确认，这是 Chrome 扩展的最小权限机制。
  • API Key 只保存在浏览器本地存储（chrome.storage.local），不会上传到你选择的 AI 服务商之外的任何服务器。
