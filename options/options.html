Rewrite Prompt (system prompt)

Notes

  • Target Reading Level is the CEFR level a page is rewritten to when you turn rewrite mode on. If a paragraph is still too hard, hover it and click the small ↓ button in its left margin to rewrite just that paragraph one level lower (B1 → A2 → A1); click the level label next to it to switch that paragraph between the levels you've already loaded and the original text. A level change here applies the next time you turn rewrite mode on for a page.
  • The rewrite prompt above is fully editable — the built-in prompt (shown for the level selected above) turns page text in any language into English at that CEFR level (English text is simplified, other languages are translated), keeping the original meaning, shortening long sentences, and replacing rare words, with short English glosses added for any hard words that remain, but you can replace it with your own (a different target language, a different rewrite style). It must still ask the model to return a JSON array of strings with exactly as many items as the input, in order — otherwise the extension won't be able to parse the response. Write {{level}} anywhere in a custom prompt to have it replaced with the level being requested; a custom prompt without {{level}} is used as-is for the page, and the per-paragraph ↓ button falls back to the built-in prompt. Use "Reset to default" to restore the built-in prompt.
  • OpenAI: calls api.openai.com/v1/chat/completions, requires an OpenAI API key.
  • Anthropic Claude: calls api.anthropic.com/v1/messages, requires an Anthropic API key.
  • Ollama: connects to Ollama Cloud by default (https://ollama.com) — enter your Ollama API key; for local Ollama, change Base URL to http://localhost:11434, which usually needs no API key.
  • Custom: any service compatible with the OpenAI /chat/completions protocol (a self-hosted gateway, another model provider, etc).
  • Changing Base URL to a non-default address triggers a one-time permission prompt from the browser — this is Chrome extensions' least-privilege mechanism.
  • Your API key is only stored in the browser's local storage (chrome.storage.local) and is never sent to any server other than the AI provider you choose.
